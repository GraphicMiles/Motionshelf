# MotionShelf

A curated index of open-source UI components, animation libraries, agent tools, and developer utilities.

Explore the [library](https://motionshelf.onrender.com/), search and save resources, and follow the links to their original projects. The [interactions](https://motionshelf.onrender.com/interactions.html) collection has six configurable, copyable examples with vanilla JavaScript, React, Vue, and Svelte exports.

## Contribute

Suggest a resource from the website or open a pull request. Provide a description, original source link, and license; a JSON metadata file can fill the form. Submissions are reviewed before publication. Copyable MotionShelf examples are curated separately; submitted code is not uploaded or executed.
