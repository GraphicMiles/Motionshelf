# MotionShelf

A library of copyable first-party UI examples and offline developer tools, alongside selected links to upstream open-source projects.

Explore the [library](https://motionshelf.onrender.com/) to preview working examples, copy source or setup commands, and download the files. The [interactions](https://motionshelf.onrender.com/interactions.html) collection also includes six examples with vanilla JavaScript, React, Vue, and Svelte exports.

## Contribute

Use [Contribute](https://motionshelf.onrender.com/contribute) to submit a public page, a GitHub source URL, or bounded source files for review. Uploaded code is inspected as data, never executed. Nothing is published automatically.
