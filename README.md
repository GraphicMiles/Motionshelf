# MotionShelf

A curated index of open-source UI components, animation libraries, agent tools, and developer utilities.

Explore the [library](https://motionshelf.onrender.com/), search and save resources, and follow the links to their original projects.

## Contribute

Suggest a resource from the website or open a pull request. Include a clear description, the original source, and its license. Submissions are reviewed before publication.
