# Particle field — vanilla

Open index.html from a local HTTP server (ES modules do not run reliably from file://).

Give the component a parent with an explicit height (for example 320px); it fills that space. The component uses the same core.js, style.css and base.css as the live preview. Adjust the numeric defaults in the component or pass them as props where supported. The mount function returns update(options), replay(), and destroy() for lifecycle control. Reduced-motion settings are respected.

Settings: radius (40–200px), strength (6–55px).

Font files are included for the preview typography. The DM Sans and Space Grotesk fonts are available from Google Fonts under the SIL Open Font License. Their license notices are included in the fonts folder. See https://openfontlicense.org/.
